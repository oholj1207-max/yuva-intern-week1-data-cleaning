# YUVA Intern - Week 1 Data Cleaning

## Project Overview
This project focuses on data acquisition, cleaning, preprocessing, and outlier visualization using Python.

## Dataset
The Titanic dataset was used for this project.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed
- Loaded the dataset
- Explored the dataset structure
- Checked missing values
- Handled missing values
- Checked duplicate records
- Detected outliers
- Created boxplots for Fare and Age
- Saved the cleaned dataset

## Files
- `week1_data_cleaning.py` - Python source code
- `titanic_cleaned.csv` - cleaned dataset
- `fare_boxplot.png` - Fare outlier visualization
- `age_boxplot.png` - Age outlier visualization

## Conclusion
The dataset was cleaned and preprocessed successfully and is ready for further analysis.
